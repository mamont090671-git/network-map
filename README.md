# Карта локальной сети

Веб-приложение для визуализации и редактирования топологии сети.

## Запуск

```bash
cd network-map
./start.sh
# или: npm install && npm start
```

Сервер запустится на `http://0.0.0.0:3000`.

## Возможности

- **Узлы**: добавление, удаление, редактирование сетевых узлов
  - 10 типов: сервер, свитч, роутер, фаервол, ПК, принтер, хранилище, телефон, точка доступа, другое
  - Поля: название, тип, IP Nebula, публичный IP, локальный IP, описание
  - Drag-n-drop перемещение
- **Связи**:
  - Физические (Ethernet, оптика) — сплошная зелёная линия
  - WiFi — синяя пунктирная
  - Виртуальные (VLAN, VPN) — зелёная пунктирная
  - Создание: перетаскивание от коннектора (🔴) к целевому узлу
  - Удаление: клик по красному ✕ на связи
  - Редактирование: клик по связи → меню → редактировать
- **Навигация**:
  - Колесо мыши — масштабирование (0.2x — 3x)
  - Перетаскивание фона — панорамирование
  - Мини-карта (правый нижний угол)
  - Кнопки зума (левый нижний угол)
- **Сохранение**: автосохранение в `data.json` (debounce 300ms)
- **Экспорт/Импорт**: JSON-файл
- **Клавиатура**: Delete — удалить выбранный узел, Escape — закрыть модалку
- **Контекстное меню**: ПКМ на узле

## Структура

```
network-map/
├── server.js          # Fastify сервер (API + статика)
├── public/
│   ├── index.html     # HTML + inline CSS
│   └── app.js         # Клиент: Canvas/SVG рендеринг, CRUD, навигация
├── data.json          # Мага (nodes + links)
├── start.sh           # Скрипт запуска с проверками
├── .gitignore
└── package.json
```

## API

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/map | Получить текущую карту `{nodes, links}` |
| POST | /api/map | Сохранить карту `{nodes, links}` |
| POST | /api/shutdown | Остановить сервер |

## Текущая карта (data.json)

7 узлов, 7 связей. lighthouse RU — центральный хаб (все связи идут от него).

## Примечания

- Требуется Node.js 18+
- Данные хранятся в файле `data.json` (нет бэкапов)
- Нет аутентификации — только для доверенной среды

# Карта локальной сети

Веб-приложение для визуализации и редактирования карты сети.

## Запуск

```bash
cd network-map
npm install
npm start
# или: node server.js
```

Сервер запустится на `http://localhost:3000`

## Возможности

- **Узлы**: добавление, удаление, редактирование сетевых узлов
  - Типы: сервер, свитч, роутер, фаервол, ПК, принтер, хранилище, телефон, точка доступа
  - Поля: название, тип, IP-адрес, описание
  - Перетаскивание узлов мышью
- **Связи**:
  - Физические (Ethernet, оптика) — сплошная линия зелёного цвета
  - Виртуальные (VLAN, VPN) — пунктирная линия фиолетового цвета
  - Создание: тяни от коннектора (красная точка) одного узла к другому
  - Редактирование/удаление: клик по связи → контекстное меню
- **Навигация**:
  - Колесо мыши — масштабирование
  - Перетаскивание фона — панорамирование
  - Мини-карта в правом нижнем углу
- **Сохранение**: автосохранение в `data.json`
- **Экспорт/Импорт**: сохранение карты в JSON-файл и загрузка из файла

## Структура

```
network-map/
├── server.js          # Fastify сервер
├── public/
│   ├── index.html     # HTML + CSS
│   └── app.js         # Клиентская логика
├── data.json          # Данные карты (узлы + связи)
└── package.json
```

## API

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/map | Получить текущую карту |
| POST | /api/map | Сохранить карту (nodes + links) |
